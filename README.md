# The Y Standard Library
*By Kenneth Pollick 2022-2026 All Rights Reserved.* [^1]

The Y Standard Library is, as its name implies, the standard library of [the Y Programming Language](https://www.kennethpollick.com/software/y.html), which I've been working on for some years off and on now.
Currently this repository contains sublibraries, examples for Y, and development notes for Y and the standard library. The examples and development notes will be moved during or after design is finished, and the library and sublibraries will be restructured as development completes.
I am finally working on the compiler ([Y Compiler and Interpreter (YCI)](https://www.kennethpollick.com/software/yci.html)) as the semantics are settled; during this, I will be finalizing the design of the main standard libraries and small pieces of the language.

To find more information about Y after perusing this repository, join [The Y Discord Server](https://discord.gg/AdjxzFjPNs), watch Y language and standard library development streams on [My Youtube Channel](https://www.youtube.com/channel/UCE1Lhhv_5oXUv4oiKbmsVnA/videos) or [My Twitch Channel](https://www.twitch.tv/kennythelogician), or check out [My Personal Site](https://www.kennethpollick.com) or [My Patreon](https://www.patreon.com/KennethPollick).

[^1]: Note, I currently have not chosen a license since I haven't looked into the full legal implications of them, but as the standard library will be included in the compiler, you will of course be able to use it.
